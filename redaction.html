Espace rédaction

Ajouter un événement ou un article

Remplissez le formulaire : la page prépare le texte à coller dans le bon fichier du site. Aucune connaissance technique n'est nécessaire.

Aperçu

Texte à copier


              

                
                Ouvrir le fichier sur GitHub
              

              
    
                
  1. Cliquez sur « Copier le texte ».
    2. 
                
  2. Ouvrez le fichier data/evenements.js sur GitHub (bouton ci-dessus, puis l'icône crayon si besoin).
    3. 
                
  3. Collez le texte sur la ligne juste après window.EVENEMENTS = [.
    4. 
                
  4. Cliquez sur « Commit changes ». Le site est à jour en une à deux minutes.

Texte à copier

              

              

                
                Ouvrir le fichier sur GitHub
              

              
    
                
  1. Cliquez sur « Copier le texte ».
    2. 
                
  2. Ouvrez le fichier data/articles.js sur GitHub.
    3. 
                
  3. Collez le texte sur la ligne juste après window.ARTICLES = [.
    4. 
                
  4. Pour une photo, déposez-la d'abord dans le dossier assets/img (« Add file », puis « Upload files »).
    5. 
                
  5. Cliquez sur « Commit changes ». L'article est en ligne en une à deux minutes.
    6.
